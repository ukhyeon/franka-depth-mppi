# Baseline R이 손을 충분히 피하지 않은 이유

기존 R과 관절·명령 궤적이 비트 단위로 같은 진단 재생에서 확인했다. **R에도 환경 비용이 있지만 손 표면과 겹친 구 중심의 ESDF가 미관측이면 비용이0이었다.**

| step163 (2.716667s) | 값 |
|---|---|
| 링크 / 전역 sphere index | panda_link5 / 30 |
| 구 중심 xyz(m) | 0.557693, 0.020007, 0.519709 |
| 반지름 | 원래50mm + 계획buffer20mm |
| ROI 관측면과 거리 | 원래 구−9.54mm / buffer 포함−29.54mm |
| 중심 raw ESDF | −100: 미관측/질의 불가 sentinel, 실제−100m 거리가 아님 |
| 해당 구 nvblox 비용 |0|
| 가장 가까운 손 관측점 raw ESDF |0: 유효 표면 voxel|

![광선 및 ESDF 분석](images/nvblox-observation-diagnosis.png)

후속 광선 분석에서 sphere30 중심은 손끝 위의 깊이 반환이 없는 영상 영역에 있었다. 일부 그리퍼 중심은 손바닥 뒤의 가려진 영역에 있었다. 구 외곽이 관측점과 겹쳐도 중심은 미관측일 수 있다. 화면의3cm 표시 복셀이 보인다는 사실은 로봇 중심에서 ESDF가 유효하다는 증거가 아니다.

- 실제 겹침7시점(step158–164)에서 로봇 전체 구의 nvblox 비용 합은0.
- 선택된 MPPI 후보의 손 ROI 겹침 구·시점에서도 비용0.
- 다른 예측 위치에서는 양수 nvblox 비용 발생. 환경 비용 전체가 비활성인 것이 아님.
- 대표7시점의 CUDA graph 후보 비용과 같은 후보의 최신 지도 독립 재질의는 원소 단위 동일.
- step163 선택후보 #141의 할인 총비용60,452.047 중 nvblox3,184.658은 손 ROI 겹침 위치와 다른 예측 위치에서 발생. “목표 비용이 정상 손 충돌 페널티를 압도했다”고 결론낼 수 없음.
- 예측·실제 상태 차이도 있지만 예측 자체가 이미 겹쳐 있어 이것만으로 설명 불가.

근거 CSV: [최근접 실제 상태150–175](data/R-nvblox-nearest.csv), [MPPI 후보 진단 요약](data/R-candidate-summary.csv). 이 값은 **buffer 포함** 거리이며 README의 buffer 제외 거리와20mm 차이 난다.

이 때문에 R→LOW는 대상 형상 표현 보강과 추가 비용 도입 효과를 함께 포함한다. LOW→HIGH만 동일 ROI 표현에서의 활성 거리 변경 비교다. 이 진단에서는 미관측 비용 처리, 비용 weight, 충돌 구, 지도 및 MPPI 설정을 바꾸지 않았다.

`feasible=true`는 설정된 반환 명령 상태의 제약 검사를 통과했다는 뜻이다. 실제 관측면과 비접촉, horizon 전체 비충돌, 미관측 공간 안전을 뜻하지 않는다. 구 중심의 block 부재와 해당 voxel의 observed=false는 raw sentinel만으로 구분하지 못했다.
